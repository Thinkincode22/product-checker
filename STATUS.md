## 📊 Система диагностики (3 уровня)

### Уровень 1: Автоматические логи
- `[App]` - ход выполнения приложения
- `[Gemini]` - ответы API
- `[drawBoxes]` - процесс рисования

### Уровень 2: Test Heatmap кнопка
- Рисует тестовый прямоугольник
- Проверяет, работает ли canvas вообще

### Уровень 3: Export Diagnostics кнопка
- Полный анализ всех данных
- Рекомендации по проблемам
- Детальная информация о масштабировании

---

## 🐛 Типичные проблемы и решения

| Проблема | Диагностика | Решение |
|----------|-------------|---------|
| Нет красных зон | `hasMissing: false` в логах | Использовать более разные фото или проверить API |
| Canvas не рисует | Test Heatmap не работает | Проверить браузер и консоль на ошибки |
| Зоны в неправильном месте | Export Diagnostics показывает wrong scale | Масштабирование проблема (редко) |
| Видна 1 из 2 зон | Export показывает `scaledWidth < 2` | Одна зона слишком мала |
| API Key error | "Please set your API Key" | Установить ключ в settings |

## 🎯 Ключевые технические моменты

### Масштабирование координат
```javascript
// Gemini возвращает: [100, 200, 300, 400] в разрешении 4000x3000
// На экране: 300x225 пиксели
// Масштаб: 300/4000 = 0.075

// Результат на экране: [7.5, 15, 22.5, 30]
```

### Canvas рендеринг
```javascript
// 1. Создать canvas с display размером
// 2. Позиционировать как absolute overlay
// 3. Рисовать прямоугольники с полупрозрачной заливкой
// 4. Добавить белый текст с красным контуром
```

### Валидация координат
```javascript
// Проверка: x1 < x2, y1 < y2
// Клипование: максимум = naturalWidth/Height
// Пропуск: если размер < 2 пиксели
```
