## 🎯 Чекборды для разных ситуаций

### Ситуация 1: Я совсем не знаю, с чего начать

```
[ ] 1. Прочитай "Quick Start" в README.md
[ ] 2. Установи зависимости: npm install
[ ] 3. Запусти приложение: npm run dev
[ ] 4. Поменяй API ключ (если нужно)
[ ] 5. Загрузи 2 фото и нажми "Compare"
[ ] 6. Если все работает - отлично! 🎉
[ ] 7. Если не работает - переходи к ситуации 2
```

### Ситуация 2: Теплова карта не показывает красные зоны

```
[ ] 1. Открой DevTools (F12 → Console)
[ ] 2. Прочитай разделы в DIAGNOSTICS_GUIDE.md:
    [ ] "1. Перевір, чи взагалі генерується маска"
    [ ] "2. Переконайся, що шар теплової карти рендериться"
    [ ] "3. Перевір масштабування координат"
[ ] 3. Если логи показывают hasMissing: true, но нет canvas:
    [ ] Попробуй тестовую кнопку "Test Heatmap (Debug)"
[ ] 4. Если тестовая карта видна, проблема в координатах
[ ] 5. Нажми "Export Diagnostics" и посмотри результат
[ ] 6. Найди свой сценарий в DIAGNOSTICS_GUIDE.md и примени решение
```

### Ситуация 3: Логи говорят hasMissing: false

```
[ ] 1. Проверь, что фото действительно показывают разные полки
[ ] 2. Проверь, что API ключ верный (в settings)
[ ] 3. Сделай снимки с большей разницей
[ ] 4. Попробуй другие фото
```

### Ситуация 4: Красные зоны в неправильном месте

```
[ ] 1. Нажми "Export Diagnostics"
[ ] 2. В консоли найди блок "boxesAnalysis"
[ ] 3. Смотри на "scaled" vs "original" координаты
[ ] 4. Посмотри "scale" в "imageInfo"
[ ] 5. Если scale = [0.1, 0.1], то координаты масштабируются на 10%
[ ] 6. Проверь, что originalBox находится в границах изображения
```
