# 🔧 Інструкція з використання діагностики

## Що змінилось?

Я додав 3 рівні діагностики для швидкого виявлення проблеми з тепловою картою:

---

## 📊 Рівень 1: Автоматичні логи в консолі

Після натискання **"Compare Photos"** в консолі (F12 → Console) буде виведено:

### `[App]` логи
```
[App] Starting image comparison...
[App] Comparison result: {
  hasMissing: true,
  missingCount: 2,
  missing: [ { label: "Singleton", box: [100, 200, 300, 400] }, ... ],
  summary: "Found 2 missing items"
}
[App] Image loaded, drawing heatmap...
```

**Що шукати:**
- Чи `hasMissing: true`?
- Чи `missingCount > 0`?
- Чи є координати в `box`?

### `[Gemini]` логи
```
[Gemini] Successfully parsed response: { missing: [...], summary: "..." }
```

**Що шукати:**
- Чи модель повертає результати?

### `[drawBoxes]` логи
```
[drawBoxes] Called with boxes: [...]
[drawBoxes] Image dimensions: { displayed: {...}, actual: {...}, scale: {...} }
[drawBoxes] Drawing box 0: { original: {x1, y1, x2, y2}, scaled: {...} }
[drawBoxes] Canvas created: { width: 300, height: 225 }
[drawBoxes] Successfully drew 2 out of 2 boxes
```

**Що шукати:**
- Canvas має нульовий розмір?
- Скільки boxes насправді малюється?
- Чи координати масштабуються правильно?

---

## 🧪 Рівень 2: Кнопка "Test Heatmap (Debug)"

Коли результати аналізу показані, натисни **🧪 Test Heatmap (Debug)**

**Що робить:**
- Малює червоний прямокутник на 20%-40% від центру зображення
- Виводить інформацію про розміри в консоль

**Якщо червоний прямокутник видно:**
✅ Canvas працює, проблема в координатах або даних від Gemini

**Якщо червоний прямокутник НЕ видно:**
❌ Проблема в canvas, стилях або DOM

---

## 📊 Рівень 3: Кнопка "Export Diagnostics"

Натисни **📊 Export Diagnostics** після аналізу

**Що виводить:**
Повний звіт з:
- Інформацією про зображення (природний розмір vs відображуваний)
- Коефіцієнтами масштабування
- Аналізом кожного box (оригінальні координати, масштабовані, площа)
- Проблемами в координатах (якщо вони є)

Приклад:
```javascript
[Diagnostics] Full Diagnostics Report:
{
  timestamp: "2024-01-23T10:30:45.123Z",
  result: { missingCount: 2, missing: [...] },
  imageInfo: {
    naturalWidth: 4000,
    naturalHeight: 3000,
    offsetWidth: 300,
    offsetHeight: 225,
    scale: { x: 0.075, y: 0.075 }
  },
  boxesAnalysis: [
    {
      label: "Singleton",
      originalBox: { x1: 100, y1: 200, x2: 300, y2: 400, width: 200, height: 200 },
      scaledBox: { x1: 8, y1: 15, x2: 23, y2: 30, width: 15, height: 15 },
      analysis: { valid: true, issues: [], size: { width: 200, height: 200, area: 40000, areaPercent: "0.33%" } }
    }
  ]
}
```

## ✅ Чеклист діагностики

Послідовно виконай ці кроки:

1. **Завантажь 2 фото** (наприклад, полку до та після)

2. **Натисни "Compare Photos"**

3. **Відкрий DevTools (F12) → Console**

4. **Перевір логи `[App]`:**
   - [ ] Чи результат містить `hasMissing: true`?
   - [ ] Чи `missingCount > 0`?
   - [ ] Чи видны координати в `missing`?

5. **Якщо все гаразд з логами, натисни "🧪 Test Heatmap (Debug)"**
   - [ ] Чи видна червона зона на зображенні?
   - [ ] Чи видны логи `[Debug]`?

6. **Натисни "📊 Export Diagnostics"** и переглянь повний звіт

7. **Проаналізуй результати:**

   - **Сценарій 1: Логи говорять "hasMissing: false"**
     → Проблема в Gemini API або даних. Перевір API ключ

   - **Сценарій 2: Логи говорять "hasMissing: true", але теплової карти не видно**
     → Натисни Test Heatmap:
       - Якщо тестова карта видна → Проблема в координатах Gemini
       - Якщо тестова карта НЕ видна → Проблема в canvas

   - **Сценарій 3: Усе видно, але зони в неправильному місці**
     → Перевір "Export Diagnostics" - масштабування неправильне

## 💻 Приклад виконання (full workflow)

```bash
1. Користувач завантажує 2 фото
2. Натискає "Compare Photos"
3. Чекає обробку
4. Результати: "Found 2 missing items: Singleton, Jack Daniels mini"
5. Видимо 2 червоні зони на фото ✓

ЯКЩО червоні зони НЕ видно:
6. Натискає "Test Heatmap (Debug)"
7. На фото з'являється тестова червона зона
   → Значить canvas працює, проблема в координатах
8. Натискає "Export Diagnostics"
9. У консолі виводиться детальний звіт
10. Видно, що scaledWidth = 1 або scaledHeight = 1
    → Координати занадто малі після масштабування
```

## 🐛 Типові проблеми та розв'язки

### ❌ Проблема: hasMissing = false (модель не знайшла різниці)

**Розв'язок:**
- Перевір, чи фото насправді відрізняються
- Перевір API ключ
- Спробуй інші фото

### ❌ Проблема: Canvas видно, але немає червоних зон

**Розв'язок:**
1. Натисни Test Heatmap
2. Якщо видна тестова зона → перейди до наступної проблеми
3. Якщо НЕ видна → canvas не працює, перевір браузер

### ❌ Проблема: Червоні зони в неправильному місці

**Розв'язок:**
1. Натисни Export Diagnostics
2. Перевір `scale` в `imageInfo`
3. Порівняй `originalBox` та `scaledBox`
4. Якщо різниця дивна → масштабування неправильне

### ❌ Проблема: Видна 1 зона з 2

**Розв'язок:**
1. Натисни Export Diagnostics
2. Перевір `analysis` для всіх boxes
3. Один box може мати `scaledWidth < 2` → занадто малий
4. Модель може не визначити одну область

## 📝 Збереження логів для подальшого аналізу

Якщо потрібна допомога:

4. Додай також скріншот з тепловою картою
